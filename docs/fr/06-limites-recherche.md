# 6. Limites de la recherche

Les notes de recherche ne constituent pas une spécification complète ni une preuve de sécurité pour une intégration de production. Ce chapitre recense les hypothèses, les paramètres et les points qui demandent une validation indépendante. Aucune installation ni exécution n’est réalisée.
