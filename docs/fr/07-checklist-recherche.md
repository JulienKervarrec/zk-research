# 7. Checklist de lecture

Identifier le modèle de preuve, les hypothèses, les paramètres, les données publiques et le verifier. Rechercher ensuite les limites déclarées et les interfaces non couvertes. Cette checklist aide à transformer une note de recherche en base de travail sans surpromesse.
